🛠️ Technologie

Web Components Standard: Der Wochenplaner nutzt moderne Web Components (Custom Elements) für eine modulare und wartbare Architektur.
Lokale Speicherung: Alle Termine werden im Browser LocalStorage gespeichert und bleiben über Sessions hinweg erhalten.
Responsive Design: Das Layout passt sich automatisch an verschiedene Bildschirmgrößen an.
